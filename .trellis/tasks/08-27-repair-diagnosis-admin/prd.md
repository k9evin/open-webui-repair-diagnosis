# 实现返修管理界面

## Goal

实现初始 XLSX 导入、SOP 管理和案例审核管理入口。

## Requirements

- 导入显示映射、PN 异常、空字段、重复提示、清洗预览和逐行结果；保留原始行号与字段。
- SOP 管理维护版本、适用产品范围、内容和生效日期。
- 管理员可导入 Work Requirements/debug 文档，指定类型、版本和适用 metadata；导入结果建立全文和向量索引。
- 审核人员可补充规范化文本/适用范围/质量并批准、拒绝或退回 pending 案例。

## Acceptance Criteria

- [ ] 导入记录可追溯到源文件和行号，且不会覆写原始字段。
- [ ] SOP 与审核的变更受角色保护并写入审计。
- [ ] 批准案例能在返修检索中出现，拒绝/待审核案例不会出现。
