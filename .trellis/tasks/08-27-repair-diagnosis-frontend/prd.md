# 实现返修诊断页面

## Goal

复用现有组件实现诊断页面、结果卡片和反馈弹窗。

## Requirements

- 固定必填 PN、SN、产品类型、分厂和故障描述；失效类型/已执行步骤可选。
- 三栏显示输入、建议文本以及 SOP/案例卡片；SN 默认脱敏。
- 反馈弹窗自动带入查询信息，最小收集结果、是否换件、换件 PN（如有）和实际操作；测量状态支持已测量/未测量/不适用。

## Acceptance Criteria

- [ ] 必填校验、加载/错误状态和 API 鉴权与现有前端惯例一致。
- [ ] 案例卡片完整展示 PRD 指定字段和匹配范围。
- [ ] 页面不会复用或改变普通聊天的检索请求。
